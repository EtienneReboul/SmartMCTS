# Installation

## Stable release

To install Smart MCTS, run this command in your terminal:

```sh
uv add smart-mcts
```

Or if you prefer to use `pip`:

```sh
pip install smart-mcts
```

## From source

The source files for Smart MCTS can be downloaded from the [Github repo](https://github.com/EtienneReboul/smart-mcts).

You can either clone the public repository:

```sh
git clone https://github.com/EtienneReboul/smart-mcts
```

Or download the [tarball](https://github.com/EtienneReboul/smart-mcts/tarball/main):

```sh
curl -OJL https://github.com/EtienneReboul/smart-mcts/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd smart-mcts
uv sync
```
